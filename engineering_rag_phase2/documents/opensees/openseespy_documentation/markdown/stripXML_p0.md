## 7.23. stripXML command

**stripXML(*inputml*, *outputdata*, *outputxml*)**

Strip a xml file to a data file and a descriptive file.

| `inputxml` ([str](https://docs.python.org/3/library/stdtypes.html#str)) | input xml file name. |
| --- | --- |
| `outputdata` ([str](https://docs.python.org/3/library/stdtypes.html#str)) | output data file name. |
| `outputxml` ([str](https://docs.python.org/3/library/stdtypes.html#str)) | output xml file name. |
