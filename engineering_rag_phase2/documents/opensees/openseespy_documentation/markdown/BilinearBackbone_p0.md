## 4.14.5.40.1.2. BilinearBackbone

**hystereticBackbone(*'Bilinear'*, *backboneTag*, *e1*, *s1*, *e2*, *s2*)**

The backbone function is bilinear defined by two controlling points
\((e_1, s_1)\) and \((e_2, s_2)\).

| `backboneTag` ([int](https://docs.python.org/3/library/functions.html#int)) | integer tag identifying the backbone function. |
| --- | --- |
| `e1` ([float](https://docs.python.org/3/library/functions.html#float)) | parameter \(e_1\). |
| `s1` ([float](https://docs.python.org/3/library/functions.html#float)) | parameter \(s_1\). |
| `e2` ([float](https://docs.python.org/3/library/functions.html#float)) | parameter \(e_2\). |
| `s2` ([float](https://docs.python.org/3/library/functions.html#float)) | parameter \(s_2\). |
