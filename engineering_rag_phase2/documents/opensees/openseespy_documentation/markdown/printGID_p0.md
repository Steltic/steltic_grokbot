## 6.28. printGID command

**printGID(*filename*, *'-append'*, *'-eleRange'*, *startEle*, *endEle*)**

Print in GID format.

| `filename` ([str](https://docs.python.org/3/library/stdtypes.html#str)) | output file name. |
| --- | --- |
| `'-append'` ([str](https://docs.python.org/3/library/stdtypes.html#str)) | append to existing file. (optional) |
| `startEle` ([int](https://docs.python.org/3/library/functions.html#int)) | start element tag. (optional) |
| `endEle` ([int](https://docs.python.org/3/library/functions.html#int)) | end element tag. (optional) |
