## 5.3.4. SuperLU SOE

**system(*'SuperLU'*)**

This command is used to construct a SparseGEN linear system of equation object. As the name implies, this class is used for sparse matrix systems. The solution of the sparse matrix is carried out using [SuperLU](http://crd.lbl.gov/~xiaoye/SuperLU/).
