## 7.14. setNodeCoord command

**setNodeCoord(*nodeTag*, *dim*, *value*)**

set the nodal coodinate at the specified dimension.

| `nodeTag` ([int](https://docs.python.org/3/library/functions.html#int)) | node tag. |
| --- | --- |
| `dim` ([int](https://docs.python.org/3/library/functions.html#int)) | the dimension of the coordinate to be set. |
| `value` ([float](https://docs.python.org/3/library/functions.html#float)) | coordinate value |
