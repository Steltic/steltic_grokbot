## 7.7. reactions command

**reactions(*'-dynamic'*, *'-rayleigh'*)**

Calculate the reactions. Call this command before the [`nodeReaction()`](https://openseespydoc.readthedocs.io/en/latest/src/nodeReaction.html#nodeReaction).

| `'-dynamic'` ([str](https://docs.python.org/3/library/stdtypes.html#str)) | Include dynamic effects. |
| --- | --- |
| `'-rayleigh'` ([str](https://docs.python.org/3/library/stdtypes.html#str)) | Include rayleigh damping. |
