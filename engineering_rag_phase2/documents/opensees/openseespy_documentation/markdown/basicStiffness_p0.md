## 6.3. basicStiffness command

**basicStiffness(*eleTag*)**

Returns the stiffness of the basic system for a beam-column element.
A list of values in row order will be returned.

| `eleTag` ([int](https://docs.python.org/3/library/functions.html#int)) | element tag. |
