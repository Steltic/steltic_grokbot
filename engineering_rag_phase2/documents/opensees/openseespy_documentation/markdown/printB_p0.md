## 6.27. printB command

**printB(*'-file'*, *filename*, *'-ret'*)**

print the right hand side of a FullGeneral system that the integrator creates to the screen or a file if the `'-file'` option is used.

| `filename` ([str](https://docs.python.org/3/library/stdtypes.html#str)) | name of file to which output is sent, by default, print to the screen. (optional) |
| --- | --- |
| `'-ret'` ([str](https://docs.python.org/3/library/stdtypes.html#str)) | return the B vector as a list. (optional) |
