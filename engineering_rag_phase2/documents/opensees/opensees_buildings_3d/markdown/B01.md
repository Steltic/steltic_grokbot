# B01 — Low-rise office (3-story), 3D space moment frame

First building of the realistic 3D library, and the one that **stands up the reusable
3D engine** every later building reuses.

## Building
3-story office, 150 ft × 90 ft (5 × 3 bays @ 30 ft), 13 ft storeys (hₙ = 39 ft),
fixed bases, rigid floor diaphragms. Lateral system modeled as a **3D space moment
frame** (every beam-column joint moment-connected). ASTM A992. Low seismic (SDC B).

## Modeling decisions
- **3D, kip-inch**, `ndm 3 / ndf 6`. Nodes at every (x-gridline, y-gridline, floor);
  integer tags `floor*10000 + ix*100 + iy`; diaphragm masters `floor*10000+9999`.
- **Rigid diaphragm** per floor (`rigidDiaphragm(3, master, *slaves)`, normal = global Z),
  master at the plan centre of mass. Master freed in UX, UY, RZ; fixed in UZ, RX, RY.
- **Mass** lumped at each master: translational (X,Y) from the floor seismic weight,
  rotational (about Z) = m·(Bx²+By²)/12 (rectangular-plan polar inertia).
- **Members** elastic `elasticBeamColumn`. Columns oriented so the strong axis resists
  the relevant sway: x-edge column lines strong about Y, all others strong about X
  (vecxz (0,1,0) vs (1,0,0)); beams use vecxz (0,0,1) so the strong axis (Iz) bends in
  the vertical plane. Beam/column inertia mapping was verified by the local-axis cross
  products.
- **Geometric transform**: `Linear` for modal/eigen; `PDelta` on columns for the
  lateral static runs (captures P-Δ at this scale).
- **Sections are ASSUMED, not designed.** W24×55 (the first guess) made the bare frame
  far too flexible (T₁ ≈ 2.35 s); since member sizing is a later tier, sizes were
  raised to **W14×132 columns / W27×94 beams**, which land the period and drift in a
  realistic, sane range. (Member design/optimization is out of scope here.)
- Gravity (D + 0.5L) applied at column nodes for the P-Δ axial state; seismic mass uses
  dead + cladding only (office, no storage live per ASCE 7 §12.7.2).

## Period
Bare-centreline elastic models omit panel zones, composite-slab stiffening, gravity
framing, and nonstructural stiffness, so they run somewhat more flexible than the real
building. The period sanity gate is a broad band, **0.5×–3× of Ta**; T₁ = 0.674 s sits
inside it.

## Results (ASCE 7-22 ELF, SDC B)
W = 3069 kip; **V = 151.8 kip**. Periods 0.674 / 0.588 / 0.552 s (T1/T2/T3).
Cumulative effective modal mass 1.00 in both directions.
**Design story drift = Cd·δ_elastic/Ie** (Cd = 3.0, ASCE 7-22 Eq. 12.8-15):
**1/387 (X)**, **1/506 (Y)** — well under the 1/50 limit (elastic 1/1163, 1/1515;
seismic demand is small at SDC B).

## Sanity checks — ALL PASS
equilibrium (X,Y), stability (min eigenvalue > 0), period (in band), modal mass ≥ 90%
(both dirs), drift (< 0.020, both dirs), base shear recovered (X,Y).

## Reusable for B02–B10
The grid builder, rigid-diaphragm + mass setup, column/beam orientation logic, the
ELF routine, the modal/effective-mass routine, the P-Δ static driver, and the
sanity-check suite all carry forward. B02 adds the design response spectrum (CQC);
later buildings add braces (CBF/dual), pinned bases, irregular plans, and setbacks.
