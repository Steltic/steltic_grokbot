EXAMPLE A-6.3 · AISC 360-22 A6 (stability bracing (Appendix 6)) · §App6 · Point Stability Bracing of a Beam, Case I (Diagonal Braces)

## Engineering Design Report

**Code basis:** ANSI/AISC 360-22, Appendix 6, Sections 6.1 and 6.3.1b (Beam Lateral Point Bracing), per the RAG extract provided.

---

### 1. Design Data

| Item | Value |
|---|---|
| Beams | Two W12x22, ASTM A992/A992M; span 28 ft; ho = 11.9 in.; adequate at Lb = 14 ft |
| Loads (per beam) | D = 0.05 kip/ft, L = 0.125 kip/ft |
| Brace point | Midspan strut + two diagonals (horizontal truss to rigid supports) |
| Diagonals | L5x5x5/16, A572/A572M Gr. 50, A = 3.07 in.², geometry 14 ft × 5 ft, L = 14.9 ft = 178.8 in. |
| Curvature | Single curvature → Cd = 1.0 |

### 2. Required Flexural Strength of Each Beam, Mr

- **LRFD:** wu = 1.2(0.05) + 1.6(0.125) = 0.260 kip/ft
  Mr = Mu = wuL²/8 = 0.260(28)²/8 = 25.5 kip-ft = **306 kip-in.**
- **ASD:** wa = 0.05 + 0.125 = 0.175 kip/ft
  Mr = Ma = 0.175(28)²/8 = 17.2 kip-ft = **206 kip-in.**

### 3. Required Point-Brace Strength — Eq. A-6-7 (App. 6, §6.3.1b)

> Pbr = 0.02 (Mr Cd / ho)  (Eq. A-6-7)

Per beam:
- **LRFD:** Pbr = 0.02(306)(1.0)/11.9 = **0.514 kips**
- **ASD:** Pbr = 0.02(206)(1.0)/11.9 = **0.346 kips**

Per App. 6, §6.1, where a bracing system braces more than one member, the required strength is based on the sum for all braced members. The midspan brace point braces both beams:

- **LRFD total:** Pbr = 2(0.514) = **1.03 kips**
- **ASD total:** Pbr = 2(0.346) = **0.692 kips**

### 4. Required Point-Brace Stiffness — Eqs. A-6-8a / A-6-8b (App. 6, §6.3.1b)

With Lbr = 14 ft = 168 in. (equal adjacent unbraced lengths):

Per beam:
- **LRFD (Eq. A-6-8a, φ = 0.75):** β_br = (1/0.75)[10(306)(1.0)/(168 × 11.9)] = (1.333)(1.53) = **2.04 kip/in.**
- **ASD (Eq. A-6-8b, Ω = 2.00):** β_br = 2.00[10(206)(1.0)/(168 × 11.9)] = 2.00(1.03) = **2.06 kip/in.**

For both beams (§6.1 summation):
- **LRFD total:** β_br = 2(2.04) = **4.08 kip/in.**
- **ASD total:** β_br = 2(2.06) = **4.12 kip/in.**

### 5. Diagonal Brace Force

The brace force acts horizontally, perpendicular to the beam axes. The diagonals (14 ft longitudinal × 5 ft transverse, L = 14.9 ft) deliver the midspan force to the supports as a plan truss; the shear in each half-span is Pbr/2, and the transverse component of each diagonal is 5/14.9 of its axial force:

F_diag = (Pbr/2)(14.9/5)

- **LRFD:** F_diag = (1.03/2)(2.98) = **1.53 kips** (compression in worst case)
- **ASD:** F_diag = (0.692/2)(2.98) = **1.03 kips** (compression in worst case)

The L5x5x5/16 diagonal must be checked as a compression member for this force (Chapter E); given the small magnitude relative to the angle's capacity, strength is satisfied by inspection and stiffness governs.

### 6. Diagonal Stiffness Verification

Axial stiffness of one diagonal resolved into the braced (transverse) direction, with cos θ = 5/14.9 = 0.336:

β_provided = (AE/L) cos²θ = [3.07(29,000)/178.8](0.336)² = (498)(0.113) = **56.1 kip/in. (one diagonal)**

Worst case, counting only the compression diagonal:

56.1 kip/in. ≥ 4.12 kip/in. (governing required total) ✓

Per App. 6, §6.1, the available stiffness (including connection flexibility, to be detailed accordingly) exceeds the required stiffness for both beams combined. **The two L5x5x5/16 diagonals are adequate.**

### 7. Summary

| Quantity | LRFD | ASD | Spec. Reference |
|---|---|---|---|
| Mr (per beam) | 306 kip-in. | 206 kip-in. | ASCE/SEI 7 combos |
| Pbr (per beam / both) | 0.514 / 1.03 kips | 0.346 / 0.692 kips | Eq. A-6-7; §6.1 |
| β_br (per beam / both) | 2.04 / 4.08 kip/in. | 2.06 / 4.12 kip/in. | Eq. A-6-8a/b; §6.1 |
| Diagonal force | 1.53 kips | 1.03 kips | statics |
| Stiffness provided (1 diagonal) | 56.1 kip/in. | 56.1 kip/in. | AE cos²θ/L |

### 8. Conclusion

The midspan point brace must provide 1.03 kips (LRFD) / 0.692 kips (ASD) strength per Eq. A-6-7 (summed over both beams per §6.1) and 4.08 / 4.12 kip/in. stiffness per Eqs. A-6-8a/b. Each L5x5x5/16 diagonal carries only ≈1.5 kips and supplies 56.1 kip/in. of stiffness — more than 13 times the requirement. The bracing system complies with AISC 360-22 Appendix 6.
