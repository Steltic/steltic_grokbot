EXAMPLE A-6.6 · AISC 360-22 A6 (stability bracing (Appendix 6)) · §J4.5 §F11 §App6 §6.3.2a · Point Torsional Stability Bracing of a Beam

## Engineering Design Report

**Code basis:** ANSI/AISC 360-22, Appendix 6, Section 6.3.2a (Beam Torsional Point Bracing, Eqs. A-6-9 through A-6-12); coped-beam element flexure per Sections J4.5 and F11 (Eq. F11-1). Per the RAG extract provided.

---

### 1. Design Data

| Item | Value |
|---|---|
| Girder | W30x90 (A992), span L = 60 ft = 720 in.; tw = 0.470 in.; ho = 28.9 in.; Iy = 115 in.⁴ |
| Brace beams | W12x40 (A992) at 5 ft o.c., span 30 ft = 360 in.; tw = 0.295 in.; Ix = 307 in.⁴; reverse curvature → β_Tb = 6EI/L |
| Brace points | n = 11 within the span; Cb = 1.0 |
| Loads | wu = [1.2(40) + 1.6(24)](15)/1000 = 1.30 kip/ft; wa = (64)(15)/1000 = 0.960 kip/ft |
| Stiffener | tst = 3/8 in., one-sided, full depth |

Doubly symmetric girder → c = t and Iyeff = Iy = 115 in.⁴ (per §6.3.2a User Note).

### 2. Required Flexural Strength of Girder, Mr

- **LRFD:** Mr = 1.30(60)²/8 = 585 kip-ft = **7,020 kip-in.**
- **ASD:** Mr = 0.960(60)²/8 = 432 kip-ft = **5,184 kip-in.**

### 3. Required Overall Torsional Brace Stiffness — Eqs. A-6-11a / A-6-11b

> β_T = (1/φ)(3.6L/(nEIyeff))(Mr/Cb)² (LRFD, Eq. A-6-11a); β_T = Ω(3.6L/(nEIyeff))(Mr/Cb)² (ASD, Eq. A-6-11b); φ = 0.75, Ω = 3.00

3.6L/(nEIyeff) = 3.6(720)/[11(29,000)(115)] = 2,592/36,685,000 = 7.07 × 10⁻⁵ (kip-in.)⁻¹

- **LRFD:** β_T = (1/0.75)(7.07 × 10⁻⁵)(7,020)² = (1.333)(3,480) = **4,640 kip-in./rad**
- **ASD:** β_T = 3.00(7.07 × 10⁻⁵)(5,184)² = 3.00(1,900) = **5,700 kip-in./rad**

### 4. Web Distortional Stiffness of Bare Girder Web — Eq. A-6-12

With no stiffener (tst bs³ term = 0):

β_sec = (3.3E/ho)(1.5 ho tw³/12) = [3.3(29,000)/28.9][1.5(28.9)(0.470)³/12] = (3,311)(0.375) = **1,240 kip-in./rad**

Per the §6.3.2a User Note, if β_sec < β_T, Eq. A-6-10 is negative and torsional bracing is ineffective due to inadequate web distortional stiffness. Here 1,240 < 4,640 (LRFD) and < 5,700 (ASD) → **full-depth web stiffeners are required.**

### 5. Required Stiffener Size — Eqs. A-6-10 and A-6-12

**Brace (W12x40 in reverse curvature) flexural stiffness:**
β_Tb = 6EI/L = 6(29,000)(307)/360 = **148,000 kip-in./rad**

From Eq. A-6-10, β_br = β_T/(1 − β_T/β_sec); inverting the series relation, the required web distortional stiffness is:

β_sec,req = [1/β_T − 1/β_Tb]⁻¹

- **LRFD:** β_sec,req = [1/4,640 − 1/148,000]⁻¹ = **4,790 kip-in./rad**
- **ASD:** β_sec,req = [1/5,700 − 1/148,000]⁻¹ = **5,930 kip-in./rad** ← governs

From Eq. A-6-12 with one-sided stiffener (bs = stiffener width):

(3.3E/ho)[1.5 ho tw³/12 + tst bs³/12] ≥ 5,930

3,311[0.375 + 0.375 bs³/12] ≥ 5,930 → 0.375 bs³/12 ≥ 1.791 − 0.375 = 1.416 → bs³ ≥ 45.3 → **bs ≥ 3.57 in.**

**Use a 4 in. × 3/8 in. full-depth one-sided stiffener** at each brace point. Per §6.3.2a, the stiffener shall extend the full depth of the braced member and be attached to the flange where the torsional brace attaches to the flange; it may be stopped short 4tw from the flange not directly attached.

### 6. Required Brace Strength — Eq. A-6-9

> Mbr = (3.6L/(nEIyeff))(Mr/Cb)²(Lbr/(500ho)) ≥ 0.02 Mr  (Eq. A-6-9)

The 0.02Mr floor governs here (as reflected in the given values):

- **LRFD:** Mbr = 0.02(585) = **11.7 kip-ft** (= 140 kip-in.)
- **ASD:** Mbr = 0.02(432) = **8.64 kip-ft** (= 104 kip-in.)

### 7. Coped W12x40 Brace Beam Flexural Check — §J4.5 / §F11

At the cope, the resisting element is the 9 in. × 0.295 in. web plate. Per the Commentary to §J4.5, element flexure may be checked using Section F11. For yielding, Eq. F11-1:

> Mn = Mp = Fy Z ≤ 1.6 Fy Sx  (Eq. F11-1)

Z = tw d²/4 = 0.295(9)²/4 = 5.97 in.³; S = tw d²/6 = 0.295(9)²/6 = 3.98 in.³

Fy Z = 50(5.97) = 299 kip-in.; 1.6 Fy S = 1.6(50)(3.98) = 319 kip-in. → **Mn = 299 kip-in.**

- **LRFD:** φMn = 0.90(299) = 269 kip-in. = 22.4 kip-ft ≥ Mu = 11.7 kip-ft ✓
- **ASD:** Mn/Ω = 299/1.67 = 179 kip-in. = 14.9 kip-ft ≥ Ma = 8.64 kip-ft ✓

### 8. Summary and Conclusion

| Quantity | LRFD | ASD | Spec. Reference |
|---|---|---|---|
| Mr (girder) | 7,020 kip-in. | 5,184 kip-in. | — |
| β_T required | 4,640 kip-in./rad | 5,700 kip-in./rad | Eq. A-6-11a/b |
| β_sec bare web | 1,240 kip-in./rad | 1,240 kip-in./rad | Eq. A-6-12 (insufficient) |
| β_sec required | 4,790 kip-in./rad | 5,930 kip-in./rad | Eq. A-6-10 (inverted) |
| Stiffener | 4 in. × 3/8 in. full depth, one-sided | same | Eq. A-6-12; §6.3.2a |
| Mbr | 11.7 kip-ft | 8.64 kip-ft | Eq. A-6-9 (0.02Mr governs) |
| Coped beam capacity | 22.4 kip-ft | 14.9 kip-ft | §J4.5 / Eq. F11-1 ✓ |

The W12x40 framing beams, acting as torsional point braces in reverse curvature, are adequate in both stiffness and strength **provided that 4 in. × 3/8 in. full-depth web stiffeners are installed on the W30x90 girder at each brace point**; the bare girder web alone is distortionally too flexible (β_sec < β_T). The design complies with AISC 360-22 Appendix 6, Section 6.3.2.
