EXAMPLE A-6.5 · AISC 360-22 A6 (stability bracing (Appendix 6)) · §D2 §App6 §6.3.1b · Point Stability Bracing of a Beam in Reverse Curvature

## Engineering Design Report

**Code basis:** ANSI/AISC 360-22, Appendix 6, Section 6.3.1b (Beam Lateral Point Bracing); tension member check per Section D2(a). Per the RAG extract provided.

---

### 1. Design Data

| Item | Value |
|---|---|
| Girder | W21x50 (A992), ho = 20.3 in., reverse curvature |
| Line loads | wu = 1.2(33 psf) + 1.6(25 psf) = 79.6 psf × 40 ft = 3.18 kip/ft; wa = 58 psf × 40 ft = 2.32 kip/ft |
| Segment B–C moment | M_B = 88.7w → Mr = 282 kip-ft (LRFD) / 206 kip-ft (ASD) |
| Cb (segment B–C) | 2.46; permitted Lb = 22.2 ft (LRFD) / 20.8 ft (ASD) |
| Brace at C | Single-angle kicker (A572 Gr. 50), 48 in. horiz. × 20 in. vert., L = 52.0 in.; cos θ = 48/52 = 0.923 |
| Cd | 2.0 (brace closest to inflection point, per Eq. A-6-7 definition) |

### 2. Required Flexural Strength, Mr

Per §6.3.1b, Mr is the largest required flexural strength within the unbraced lengths adjacent to the point brace; for segment B–C this is at B:

- **LRFD:** Mr = 88.7(3.18) = 282 kip-ft = **3,384 kip-in.**
- **ASD:** Mr = 88.7(2.32) = 206 kip-ft = **2,472 kip-in.**

### 3. Required Brace Strength at C — Eq. A-6-7 (App. 6, §6.3.1b)

> Pbr = 0.02 (Mr Cd / ho), with Cd = 2.0 for the brace closest to the inflection point in a beam subjected to double curvature bending.

- **LRFD:** Pbr = 0.02(3,384)(2.0)/20.3 = **6.67 kips**
- **ASD:** Pbr = 0.02(2,472)(2.0)/20.3 = **4.87 kips**

### 4. Required Brace Stiffness at C — Eqs. A-6-8a / A-6-8b (App. 6, §6.3.1b)

Section 6.3.1b permits: "For intermediate point bracing of an individual beam, Lbr in Equations A-6-8a or A-6-8b need not be taken as less than the maximum effective length, Lb, permitted for the beam based upon the required flexural strength, Mr." With Cb = 2.46, the permitted lengths are Lb = 22.2 ft = 266.4 in. (LRFD) and 20.8 ft = 249.6 in. (ASD):

- **LRFD (Eq. A-6-8a, φ = 0.75):**
  β_br = (1/0.75)[10(3,384)(2.0)/(266.4 × 20.3)] = (1.333)(12.5) = **16.7 kip/in.**
- **ASD (Eq. A-6-8b, Ω = 2.00):**
  β_br = 2.00[10(2,472)(2.0)/(249.6 × 20.3)] = 2.00(9.76) = **19.5 kip/in.**

### 5. Kicker Brace Force

The required brace force is horizontal at the bottom flange; the kicker is inclined (cos θ = 0.923):

- **LRFD:** Fbr = Pbr/cos θ = 6.67/0.923 = **7.22 kips (tension)**
- **ASD:** Fbr = 4.87/0.923 = **5.28 kips (tension)**

### 6. Required Angle Area

**(a) Strength — tensile yielding, Section D2(a), Eq. D2-1 (Pn = Fy Ag; φt = 0.90, Ωt = 1.67):**

- **LRFD:** Ag ≥ 7.22/(0.90 × 50) = **0.160 in.²**
- **ASD:** Ag ≥ 1.67(5.28)/50 = **0.176 in.²**

**(b) Stiffness — axial stiffness resolved into the braced direction, β = (AE/L) cos²θ ≥ β_br:**

A ≥ β_br L/(E cos²θ), with cos²θ = 0.852:

- **LRFD:** A ≥ 16.7(52.0)/(29,000 × 0.852) = **0.035 in.²**
- **ASD:** A ≥ 19.5(52.0)/(29,000 × 0.852) = **0.041 in.²**

Strength governs: **Ag ≥ 0.176 in.²**

### 7. Selection

**Select L2x2x1/8 (A572 Gr. 50), A = 0.491 in.²** ≥ 0.176 in.² ✓

Provided stiffness: β = (0.491 × 29,000/52.0)(0.852) = 233 kip/in. ≥ 19.5 kip/in. ✓ (large margin)

The smallest practical rolled angle satisfies both the Eq. A-6-7 strength and Eq. A-6-8 stiffness requirements; connection design (welds to the diaphragm and girder flange) must develop Fbr per §6.1, which requires connection and anchoring flexibility to be included in the furnished stiffness.

### 8. Summary

| Quantity | LRFD | ASD | Spec. Reference |
|---|---|---|---|
| Mr | 3,384 kip-in. | 2,472 kip-in. | — |
| Pbr at C (Cd = 2.0) | 6.67 kips | 4.87 kips | Eq. A-6-7 |
| β_br (Lbr = permitted Lb) | 16.7 kip/in. | 19.5 kip/in. | Eq. A-6-8a/b + §6.3.1b relaxation |
| Kicker force | 7.22 kips | 5.28 kips | statics |
| Required Ag (strength governs) | 0.160 in.² | 0.176 in.² | §D2(a), Eq. D2-1 |
| Selection | L2x2x1/8 | L2x2x1/8 | — |
