EXAMPLE A-6.2 · AISC 360-22 A6 (stability bracing (Appendix 6)) · §App6 §6.2.2 · Point Stability Bracing of a WT-Shape Column

## Engineering Design Report

**Code basis:** ANSI/AISC 360-22, Appendix 6, Section 6.2.2 (Point Bracing), per the RAG extract provided. Brace beam sized by mechanics with AISC Manual section properties.

---

### 1. Design Data

| Item | Value |
|---|---|
| Column | WT7x34, ASTM A992/A992M (Fy = 50 ksi) |
| Axial loads | D = 25 kips, L = 75 kips |
| Bracing | x-axis point braces at quarter points; Lbr = 7.5 ft = 90 in. |
| Brace member | W-shape, 12-ft (144 in.) simple span, braces column at midspan; stiffness = 48EI/L³ |
| E | 29,000 ksi |

### 2. Required Axial Strength of Column, Pr

- **LRFD:** Pr = 1.2(25) + 1.6(75) = **150 kips**
- **ASD:** Pr = 25 + 75 = **100 kips**

### 3. Required Brace Strength — Eq. A-6-3 (App. 6, §6.2.2)

> Pbr = 0.01 Pr  (Eq. A-6-3)

- **LRFD:** Pbr = 0.01(150) = **1.50 kips**
- **ASD:** Pbr = 0.01(100) = **1.00 kip**

### 4. Required Brace Stiffness — Eqs. A-6-4a / A-6-4b (App. 6, §6.2.2)

Adjacent unbraced lengths are equal, so Pr/Lbr is the same on each side of the brace. With Lbr = 90 in.:

- **LRFD (Eq. A-6-4a, φ = 0.75):** β_br = (1/0.75)(8 × 150 / 90) = **17.8 kip/in.**
- **ASD (Eq. A-6-4b, Ω = 2.00):** β_br = 2.00(8 × 100 / 90) = **17.8 kip/in.**

### 5. Brace Beam Sizing — Stiffness Requirement

Stiffness of a simple beam loaded at midspan: β = 48EI/L³. Setting β ≥ β_br (App. 6, §6.1 requires available stiffness ≥ required stiffness):

I_req = β_br L³ / (48E) = 17.8 × (144)³ / (48 × 29,000) = 17.8 × 2,986,000 / 1,392,000 = **38.2 in.⁴**

### 6. Brace Beam Sizing — Strength Requirement

The brace force is delivered as a midspan transverse point load; the brace beam moment is:

- **LRFD:** Mbr = Pbr L/4 = 1.50(144)/4 = **54.0 kip-in.**
- **ASD:** Mbr = 1.00(144)/4 = **36.0 kip-in.**

For a compact, laterally supported beam, the nominal flexural strength is the plastic moment, Mn = Mp = Fy Zx (Chapter F, Section F2, Eq. F2-1), with φb = 0.90, Ωb = 1.67:

- **LRFD:** Zx ≥ Mbr/(φb Fy) = 54.0/(0.90 × 50) = **1.20 in.³**
- **ASD:** Zx ≥ Ωb Mbr/Fy = 1.67(36.0)/50 = **1.20 in.³**

### 7. Selection

**Select W8x13 (ASTM A992):** Ix = 39.6 in.⁴ ≥ 38.2 in.⁴ ✓; Zx = 11.4 in.³ ≥ 1.20 in.³ ✓

Provided stiffness: β = 48(29,000)(39.6)/(144)³ = 18.5 kip/in. ≥ 17.8 kip/in. ✓ (stiffness governs; strength is a minor demand).

### 8. Reduced Design — Maximum Permitted Lc and Commentary Multiplier

Section 6.2.2 permits: "Lbr in Equations A-6-4a or A-6-4b need not be taken as less than the maximum effective length, Lc, permitted for the column based upon the required axial strength, Pr." Here Lcx = 18.6 ft = 223.2 in. Additionally, the Commentary to Appendix 6 permits the point-brace stiffness coefficient (based on an infinite number of braces) to be reduced by (2n − 1)/(2n) for n intermediate braces; n = 3 → factor = 5/6.

- **LRFD:** β_br = (5/6)(1/0.75)(8 × 150 / 223.2) = (0.833)(7.17) = **5.97 kip/in.**
- **ASD:** β_br = (5/6)(2.00)(8 × 100 / 223.2) = (0.833)(7.17) = **5.97 kip/in.**

Reduced stiffness-based moment of inertia:

I_req = 5.97 × (144)³ / (48 × 29,000) = **12.8 in.⁴**

**Select W6x9 (ASTM A992):** Ix = 16.4 in.⁴ ≥ 12.8 in.⁴ ✓; Zx = 6.23 in.³ ≥ 1.20 in.³ ✓. (Pbr and Mbr are unchanged — the relaxation applies to stiffness only.)

### 9. Summary

| Quantity | LRFD | ASD | Spec. Reference |
|---|---|---|---|
| Pbr | 1.50 kips | 1.00 kip | Eq. A-6-3, §6.2.2 |
| β_br (Lbr = 7.5 ft) | 17.8 kip/in. | 17.8 kip/in. | Eq. A-6-4a/b |
| Brace beam (full stiffness) | W8x13 | W8x13 | §6.1 (available ≥ required) |
| β_br (Lbr = Lcx = 18.6 ft, ×(2n−1)/2n) | 5.97 kip/in. | 5.97 kip/in. | §6.2.2 relaxation + Commentary |
| Brace beam (reduced) | W6x9 | W6x9 | — |

### 10. Conclusion

A W8x13 midspan-loaded brace beam satisfies the Appendix 6, Section 6.2.2 point-bracing strength (Eq. A-6-3) and stiffness (Eqs. A-6-4a/b) requirements with Lbr = 7.5 ft. Using the Section 6.2.2 provision allowing Lbr to be taken as the maximum permitted effective length (18.6 ft) together with the Commentary multiplier (2n−1)/(2n) = 5/6, the required stiffness drops from 17.8 to 5.97 kip/in. and a W6x9 is adequate.
