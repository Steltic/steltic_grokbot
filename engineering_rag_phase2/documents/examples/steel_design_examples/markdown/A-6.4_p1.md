EXAMPLE A-6.4 · AISC 360-22 A6 (stability bracing (Appendix 6)) · §App6 · Point Stability Bracing of a Beam, Case II (Column Flexural Brace)

## Engineering Design Report

**Code basis:** ANSI/AISC 360-22, Appendix 6, Sections 6.1 and 6.3.1b (Beam Lateral Point Bracing), per the RAG extract provided.

---

### 1. Design Data

| Item | Value |
|---|---|
| Beams | Two W12x22, A992; span 28 ft; ho = 11.9 in.; adequate at Lb = 14 ft |
| Loads (per beam) | D = 0.05 kip/ft, L = 0.125 kip/ft |
| Tie | 2L3x3x1/4 (A572 Gr. 50), A = 2.88 in.², L = 5 ft = 60 in., welded |
| Column | HSS8x8x1/4 (A500 Gr. C), I = 70.7 in.⁴, braced span 24 ft = 288 in., midspan load |
| Curvature | Single curvature → Cd = 1.0; E = 29,000 ksi |

### 2. Required Flexural Strength of Each Beam, Mr

- **LRFD:** wu = 1.2(0.05) + 1.6(0.125) = 0.260 kip/ft; Mr = 0.260(28)²/8 = 25.5 kip-ft = **306 kip-in.**
- **ASD:** wa = 0.175 kip/ft; Mr = 0.175(28)²/8 = 17.2 kip-ft = **206 kip-in.**

### 3. Required Brace Strength — Eq. A-6-7 (App. 6, §6.3.1b)

> Pbr = 0.02 (Mr Cd / ho)  (Eq. A-6-7)

Per beam: LRFD = 0.02(306)/11.9 = 0.514 kips; ASD = 0.02(206)/11.9 = 0.346 kips.

Per §6.1 (system braces two members, sum the requirements):

- **LRFD:** Pbr = **1.03 kips**  **ASD:** Pbr = **0.692 kips**

### 4. Required Brace Stiffness — Eqs. A-6-8a / A-6-8b (App. 6, §6.3.1b)

With Lbr = 14 ft = 168 in.:

Per beam:
- **LRFD (Eq. A-6-8a, φ = 0.75):** β = (1/0.75)[10(306)(1.0)/(168 × 11.9)] = 2.04 kip/in.
- **ASD (Eq. A-6-8b, Ω = 2.00):** β = 2.00[10(206)(1.0)/(168 × 11.9)] = 2.06 kip/in.

Both beams (§6.1):
- **LRFD:** β_br = **4.08 kip/in.**  **ASD:** β_br = **4.12 kip/in.**

### 5. Provided Brace-System Stiffness

Per §6.1, the evaluation of furnished stiffness "shall consider the flexibility of all components in the system." The tie (axial) and column (flexural) act in series.

**Tie axial stiffness:**
β_tie = AE/L = 2.88(29,000)/60 = **1,390 kip/in.**

**Column flexural stiffness (simple span, midspan point load):**
β_col = 48EI/L³ = 48(29,000)(70.7)/(288)³ = 98,414,000/23,888,000 = **4.12 kip/in.**

**Series combination:**
β_sys = [1/β_tie + 1/β_col]⁻¹ = [1/1390 + 1/4.12]⁻¹ = [0.00072 + 0.2427]⁻¹ = **4.11 kip/in.**

The column flexibility dominates; the tie contributes negligibly to system flexibility.

### 6. Adequacy Check

| Basis | β required | β provided | Result |
|---|---|---|---|
| LRFD | 4.08 kip/in. | 4.11 kip/in. | ✓ Adequate (≈0.7% margin) |
| ASD | 4.12 kip/in. | 4.11 kip/in. | Marginal (≈0.2% deficit) |

**Strength:** the tie carries Pbr = 1.03 kips axially and the column resists Mbr = Pbr(288)/4 = 74.2 kip-in. — trivial demands relative to member capacities; strength is satisfied by inspection.

### 7. Conclusion

The midspan point brace must provide Pbr = 1.03 kips (LRFD) / 0.692 kips (ASD) per Eq. A-6-7 and β_br = 4.08 / 4.12 kip/in. per Eqs. A-6-8a/b, summed for both beams per §6.1. The 2L3x3x1/4 tie in series with the HSS8x8x1/4 column provides 4.11 kip/in.: **adequate under LRFD**; under ASD the provided stiffness falls about 0.2% short of the nominal requirement. Given that the deficit is well within calculation precision, acceptance may be justified by the more refined analysis permitted in §6.1 (e.g., second-order analysis per item (a), or 2Ω times the ideal stiffness from a buckling analysis per item (b)); alternatively, bracing the column at the walkway level or using a modestly stiffer HSS removes the deficit. The LRFD design is compliant as detailed.
